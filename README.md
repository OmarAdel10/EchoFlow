# EchoFlow 🎙️⚡

**EchoFlow** is an offline-first, local AI voice assistant featuring a responsive cross-platform Flutter GUI and a high-performance Python backend server.

By running the backend locally over HTTP, EchoFlow delivers real-time speech processing, zero-latency natural language interactions, and local system integration—all without routing sensitive audio data to cloud services.
